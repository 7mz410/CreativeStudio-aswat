# aswat: changes from upstream SoundCraft

Required by the Apache License 2.0 (section 4b): files we changed carry this notice through
this list.

- Branding (user-visible only, applied by `studio/rebrand.py`): the app name aswat, the bundle id
  `ps.creative.studio.aswat`, links to aswat.studio.creative.ps and this repository. Crate names,
  settings folders and the session JSON keep their upstream names.
- No Discord buttons; community links point to Creative Studio.
- Sessions save as `.aswat`, with their own document icon (`assets/app-icon/aswat-document.*`). `.scraft`,
  upstream's extension, still opens.
- App icon: the aswat star on navy (`assets/app-icon/`).
- Removed upstream's ArtCraft brand assets (`docs/brand/`), as their brand terms require of forks.
- README (upstream's is `docs/UPSTREAM-README.md`) and NOTICE: the fork, its credits and the suite.
